# Cat Reviews Its Human

Entry for the make.fun competition "Make the AI Judge Laugh: Cat Reviews Its Human" (`u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990`).

`main.py` (Python 3.13, standard library only, no network) writes one funny single-line one-star review, written by a house cat about its human, to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
